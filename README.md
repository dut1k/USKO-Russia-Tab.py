## USKO Tab  
-Программа позволяет считать список участников  
-По этому списку составить пары выступающих/ или одиночное выступление  
-Отобразить данные выступающих  
-Указывать очки в процессе выступления и победителя  

В след. обновлении - позволит заполнить протокол арбитра

### Сервер трансляции в USKO Tab

В главном меню откройте шестерёнку, выберите «Сервер трансляции» и нажмите OK.
Сервер изначально выключен; запускается только кнопкой «Запустить сервер».
После запуска эта же кнопка предлагает остановку с подтверждением.
В компактной панели управления параметры подключения и ссылка OBS сгруппированы отдельно.
Для судейства на том же компьютере откройте вторую копию USKO Tab в режиме «Табло».
При следующем запуске программа снова открывает табло, без автозапуска сервера.

По умолчанию используется порт 8000. Выберите адрес сети соревнований:
этот адрес и порт нужны другим табло, а «Ссылка для OBS» копирует показанный рядом адрес оверлея выбранного татами.
127.0.0.1 подходит только для подключения с того же компьютера.
В локальной сети должен быть разрешён входящий доступ к выбранному порту Windows Firewall.

Панель журнала можно менять по размеру, отделять в отдельное окно и скрывать.
Вернуть её можно через «Вид → Журнал сервера». Скрытие панели не останавливает сервер.
Команды «Настройки/режим работы», «Папка журналов» и «Показать журнал» находятся
в верхней строке рядом с «Вид». «Показать журнал» возвращает также закрытую
или отделённую панель. Рядом с заголовком журнала — маленькие кнопки
отделения и закрытия; плавающее окно имеет системную рамку. Вернуть его можно
кнопкой «Примагнитить» внутри самого журнала, через «Вид → Примагнитить к основному окну»
или «Показать журнал». Кнопка внутри журнала видна всегда и доступна при отделении.
Адрес 0.0.0.0 в служебном журнале означает прослушивание всех сетевых интерфейсов;
для подключения OBS и других табло используется выбранный адрес компьютера.
Текст выделяется и копируется обычным способом; «Копировать всё» находится в меню
правой кнопки мыши. Действие «Очистить» находится внутри каждой тёмной панели рядом с её названием.
При выделении текста или прокрутке вверх новые сообщения не переключают просмотр вниз.
Переход к табло, остановка и выход при работающем сервере требуют подтверждения прерывания трансляции.

Файлы журналов находятся в `%LOCALAPPDATA%/USKO-Tab/logs` (кнопка «Папка журналов»).
Формат JSONL: время, уровень, источник и текст; исключения содержат traceback.
Серверный журнал ротируется по 5 МиБ, до трёх резервных файлов на сеанс;
журнал управления — по 1 МиБ с одним резервным файлом. Журналы старше 14 дней
удаляются при открытии серверного режима. Очистка экрана не удаляет файлы.
Журнал постоянно состоит из двух панелей: события сервера слева, HTTP-запросы справа.
Вертикальный разделитель двигается влево-вправо; ни одну панель нельзя сжать до нуля.
У каждой панели свои копирование, очистка и прокрутка. HTTP-запросы записываются всегда;
тела запросов с ФИО участников не записываются. В окне `USKO` отображается как «Программа»,
`root` и `uvicorn.error` — «Сервер», `usko.connections` — «Подключения».
В JSONL сохраняется исходное имя источника. Ответы HTTP 4xx выделяются
жёлтым, 5xx — красным.

Для запуска исходников установите `requirements.txt`. Серверный исходник и `assets`
берутся из соседнего проекта `../server_USKO-Russia-Tab`. Для сборки используйте
`python -m PyInstaller --clean --noconfirm USKO-Russia-Tab2.spec` в окружении со всеми
зависимостями. Spec включает сервер и assets в exe: на компьютере пользователя
отдельная установка сервера не нужна. Сборка напрямую из `.py` перезаписывает
одноимённый spec и не включает настройки упаковки сервера.
Проверки серверного режима: `python -B -m unittest discover -s tests -p test_server_mode.py -v`.
Они используют только localhost, временные журналы и свободные порты, без Excel и рабочего OBS.
